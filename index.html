Cloud sync

Your journal is saved to a private GitHub Gist so it syncs across your devices. The token is stored only on this device and never leaves it except to talk to GitHub.

  1. Open github.com/settings/tokens → Fine-grained tokens → Generate new.
  2. Under Account permissions, set Gists: Read and write.
  3. (Classic tokens also work — just tick the gist scope.)
  4. Generate, copy it, and paste above.
  5. On your other device, paste the same token — it finds the same Gist automatically.
  6. Tip: fine-grained tokens can expire. If sync ever says “Token expired”, just generate a new one and reconnect here. For a token that never expires, use a classic token with no expiry.
